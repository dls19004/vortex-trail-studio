# Vortex Trail Studio

Official website for **Vortex Trail Studio** – Where Chaos Becomes Play.

**Domain:** [vortextrailstudio.com](https://vortextrailstudio.com)

## Tech Stack

- Next.js (App Router)
- Tailwind CSS
- React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project in [vercel.com](https://vercel.com)
3. Add the custom domain `vortextrailstudio.com` in Vercel → Settings → Domains
